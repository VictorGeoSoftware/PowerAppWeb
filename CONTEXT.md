# Context

## Glossary

### PowerAppWeb
Mobile-first responsive web client (installable PWA) of BmApp ("PowerApp"). Parallel client; the Android app remains maintained.

### Broker
Energy broker/sales agent using the app to prepare tariff comparisons for a customer. The only end-user type.

### Granted User
A Broker present in the backend `granted_users` allowlist. Only Granted Users can use any client.

### Tier
BASIC or PREMIUM, stored on the grant record (PostgreSQL is authoritative). PREMIUM unlocks the comprehensive comparator PDF.

### Bound Device
The single client (an Android phone OR a browser) an account is bound to. Switching requires an admin reset.

### CUPS
Spanish electricity supply point code identifying a customer's supply.

### Consumption Report
Customer consumption study obtained asynchronously from a CUPS, a bill PDF, or a bill photo (job: submit → poll status → result).

### Consumption Job
Backend async job (`jobId`) that produces a Consumption Report. A failed job is never re-run: "Reintentar" submits a new job. A completed job can be *refreshed* (proposals and taxes recalculated at current prices, same `jobId`).

### Current Conditions
The customer's present contract data entered by the Broker: holder, address, supplier, power term, energy prices, extra services, taxes.

### Proposal
A retailer price offer compared against Current Conditions.

### Comparator
The calculation and table comparing Proposals with Current Conditions.

### Comparator PDF
Shareable PDF report generated by the backend from a comparison.

### Fee-First Gate
Mandatory flow order: `CONSUMPTION_REQUIRED` → `CURRENT_CONDITIONS_REQUIRED` → `UNLOCKED` (Proposals, Configuration).

### Price Update Notification
Push notice that Proposal prices changed (FCM on Android, Web Push on PowerAppWeb).

## Rejected / Ambiguous Terms

### User / Customer
Use `Broker` for the app user and `Customer` for the person whose supply is analysed.

### BmWeb
Not this project: BmWeb is the admin back-office. Do not use "web app" to mean BmWeb.
